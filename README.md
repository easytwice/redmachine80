# Red Machine 80

Сайт к 80-летию отечественного хоккея. Проект собран на Next.js 16, React 19 и TypeScript.

## Локальный запуск

```bash
npm ci
npm run dev
```

## Проверка и статическая сборка

```bash
npm run typecheck
npm run build
npm start
```

`npm run build` создаёт статические файлы в `out/`. Для предпросмотра `npm start` запускает локальный сервер на порту 3000; порт можно изменить через переменную `PORT`.

Исходники находятся в `src/`, готовые изображения, шрифты и иконки — в `public/`. Содержимое `out/` генерируется при сборке и не хранится в репозитории.
